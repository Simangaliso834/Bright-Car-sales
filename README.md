# Bright-Car-sales
A data analytics project focused on analyzing historical vehicle sales data for Bright Motors to uncover business insights, optimize dealership performance, improve inventory management, and increase profitability.
The project involves:
Data cleaning and transformation using SQL and Snowflake
Revenue and profitability analysis
Customer purchasing trend analysis
Regional sales performance evaluation
Interactive dashboard creation in Power BI or Excel
Executive-level presentation of findings and recommendations

Key analytical areas include:
Revenue by car make and model
Sales trends by fuel type and vehicle year
Regional sales performance
Profit margin analysis
Average selling price trends
Customer preference insights

The project delivers:
A structured ETL and analytics workflow
Processed datasets
SQL scripts
Interactive dashboards
A professional business presentation with actionable recommendations


Technologies used include:
Databricks / SQL
Power BI / Excel
PowerPoint / Canva
Miro / Figma for architecture planning

This project demonstrates skills in:
Data analytics
SQL development
Data visualization
Business intelligence
Dashboard design
Stakeholder reporting
Data-driven decision-making
